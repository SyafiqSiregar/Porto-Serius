# Portfolio Website - Syafiq Siregar

A personal portfolio website showcasing projects, skills, and experience. Built with a focus on modern UI/UX, responsiveness, and interactive elements.

## Features
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Elements:** 3D particles, tilt effects, and smooth scroll animations.
- **Project Showcase:** Detailed project views with galleries and descriptions.
- **Dynamic Content:** Easily updatable project data using JSON-like structures in `app.jsx`.

## Technologies Used
- **HTML5** & **CSS3**
- **JavaScript (ES6+)**
- **React** (via CDN for lightweight setup without build tools)
- **Three.js** (for background particle effects)
- **Babel** (for JSX compilation in browser)

## Setup
No build step is required. Simply open `index.html` in a modern web browser, or use a local server (e.g., Live Server extension in VS Code) for the best experience.

## Usage
- **Home:** Overview of skills, experience, and selected works.
- **Project Details:** Click on any project card to view full details.
- **Contact:** Use the CTA section or footer links to get in touch.
